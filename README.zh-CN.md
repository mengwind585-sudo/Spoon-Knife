### 你好呀！

这个仓库是 GitHub 用来演示 **fork（派生）** 一个仓库的示例。

创建一个 *fork*，就是为别人的项目建立一份你自己的副本。fork 像是原仓库与你的副本之间的一座桥：你可以向原项目提交 *Pull Request*，把你的改动贡献回去，让别人的项目变得更好。fork 是 GitHub 社交化协作的核心机制。

fork 这个仓库之后，你可以随意改动项目里的内容，然后提交 [一个 Pull Request](https://github.com/octocat/Spoon-Knife/pulls) 作为练习。

想了解更多 fork 的知识，可以看官方指南 [《Forking Projects》](http://guides.github.com/overviews/forking/)。谢谢！:sparkling_heart:
